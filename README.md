# Lumora Visuals (Fabric, Minecraft 26.1.x)

Client-side HUD + visuals mod with a glass-style menu.

* Open the menu: Right Shift (rebind in Controls -> "Lumora Visuals")
* Zoom: hold C   |   Hide HUD: H
* Config: `config/lumora.properties`

Build: push to GitHub -> Actions -> "Build Lumora" -> artifact `Lumora-jar` (a zip with the jar inside).
Local build: JDK 25 + Gradle 9.4.1 -> `gradle build` -> `build/libs/lumora-1.0.0.jar`.
